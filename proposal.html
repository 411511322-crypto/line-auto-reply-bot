一、專案執行摘要 (Executive Summary)

在數位化溝通與即時通訊成為主流的時代，LINE 在台灣具備超過 90% 的智慧型手機滲透率，是企業、創作者與個人品牌不可或缺的接觸樞紐。然而，傳統仰賴人工維護的客服模式面臨嚴重挑戰：非營業時間無法即時回覆、重複問題耗費大量工時，且容易因等待時間過長造成潛在顧客流失。

本專案「LINE 智慧客服與自動回覆機器人」以高可靠性、秒級反應及資安嚴謹性為核心指標，基於 Python 3、Flask 輕量微服務與 LINE Messaging API v3 官方套件，結合 Render 雲端容器託管與 GitHub 版本控制，建構出一套24 小時全天候自動化回應系統。經實際推演，本系統可自動消化 70% 以上的日常諮詢，並實現零人工推播費用的高效營運。

四、系統技術架構與安全規範 (Technical Architecture & Security)

4.1 技術棧選型清單 (Technology Stack)

組件維度 選用技術 技術優勢與考量
開發語言 Python 3.10+ 語法簡潔、套件生態豐沛，有利於未來快速整合大型語言模型（如 Google Gemini）。
Web 微服務 Flask 3.x 極輕量化、記憶體佔用極低、啟動快，非常適合 Webhook 事件導向架構。
官方核心 SDK line-bot-sdk v3 支援最新 Messaging API 規範，採用型別安全（Type-safe）與物件導向回覆設計。
生產 WSGI 伺服器 Gunicorn 26.x 提供生產級多 Worker 程序處理並行並發連線，保障伺服器高穩定性。
版本控制平台 Git & GitHub 落實現代版本控制規範，搭配 .gitignore 機密金鑰隔離機制。
雲端容器部署 Render (PaaS) 支援 GitHub 推送自動構建（CI/CD），提供免費 HTTPS 憑證與即時日誌監控。

4.2 資訊安全與合規設計

  1. HMAC-SHA256 簽章防偽驗證： 每個 HTTP POST 請求皆經由 X-Line-Signature 驗證標頭與 Channel Secret 運算，阻擋任何偽造的惡意偽造請求。
  2. 機密金鑰絕對隔離 (.env + .gitignore)： LINE_CHANNEL_SECRET 與 LINE_CHANNEL_ACCESS_TOKEN 完全自程式碼抽離，由伺服器環境變數注入，嚴禁 Commit 至公開倉庫。
  3. 全端 HTTPS 傳輸加密： 由 Render 與 Cloudflare 邊緣節點提供 TLS 1.3 傳輸加密，杜絕中間人竊聽。
